# AgroTec — Diseño de Software

Asistente virtual inteligente para agricultores: app móvil sencilla para organizar cultivos, recibir alertas climáticas y consultar precios de insumos y productos, incluso con baja conectividad. Proyecto final de **Diseño de Software**.

- 📘 Contexto del proyecto: [AGENTS.md](AGENTS.md)
- 📋 Requerimientos: [docs/requerimientos.md](docs/requerimientos.md)
- 🧑‍🌾 Historias de usuario: [docs/historias-usuario.md](docs/historias-usuario.md)
- 🖼️ Wireframes: [docs/wireframes/](docs/wireframes/README.md)

Autor: Juan David Jurado Paz · Universidad Cooperativa de Colombia
